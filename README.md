# AI Engineering Journey

> Building the skills to design, build, and ship real-world AI products.

I'm documenting my journey toward becoming a strong **AI Engineer** — from software engineering and machine learning fundamentals to LLMs, RAG, AI agents, and production systems.

The focus is simple:

**Learn → Build → Evaluate → Deploy → Improve**

## Engineering Approach

I don't want to learn by simply completing courses.

For every major concept:

```text
Understand
   ↓
Implement
   ↓
Experiment
   ↓
Build
   ↓
Evaluate
   ↓
Deploy
   ↓
Improve
````

The goal is to become capable of **building and engineering AI systems independently**, not just using AI tools.
